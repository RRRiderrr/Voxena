# Third-party models and runtimes

Voxena does not bundle the TTS model weights. The user chooses which model repositories to download. License terms belong to their respective upstream projects/checkpoints and can differ from Voxena itself.

- CosyVoice / Fun-CosyVoice3-0.5B-2512 — FunAudioLLM — Apache-2.0 model/project terms as published upstream.
- Fish Speech S2 Pro — Fish Audio — Fish Audio Research License for the selected model. Review upstream terms before commercial use.
- XTTS v2 — Coqui — Coqui Public Model License.
- F5-TTS Russian checkpoint by hotstone228 — CC BY-NC-SA 4.0. The F5-TTS software has its own upstream license.
- Qwen3-TTS 1.7B Base and CustomVoice — Qwen — Apache-2.0 as published upstream.
- Chatterbox Multilingual V3 — Resemble AI — MIT software/model repository terms as published upstream; generated audio includes the upstream watermarking mechanism.
- Gemma 4 compact stress helper checkpoint — Google — Apache-2.0 as published for that checkpoint.
- Microsoft Edge WebView2 SDK/runtime — Microsoft terms.
- uv — Astral.
- FFmpeg — FFmpeg project license terms and the selected redistributed build's notices.

Always review the current license shown on the model's upstream page before redistributing model files or using generated material commercially.
