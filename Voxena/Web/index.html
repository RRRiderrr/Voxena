ABOUT
Voxena 
A local multi-engine voice studio with reusable voice cloning and model isolation.
.NET Framework 4.7.2WebView2Local inference
Six synthesis engines
Install only the engines you want. Each model keeps its own Python environment and weights beside Voxena.
Private by design
Scripts, cloned voice references, transcripts and generated audio stay on your PC. Network access is used to download selected open model packages.
Invisible stress preprocessing
For Russian text, a compact local Gemma 4 helper can uppercase stressed vowels internally before the text reaches the selected speech model.
Licenses differ
Every model card shows its upstream license. Some models restrict commercial use; check the terms before publishing generated material commercially.
