## ✨ Что такое Voxena?

Voxena — это настольная студия для Windows, построенная вокруг **локального AI-синтеза речи**. Вместо привязки к одной модели или облачному сервису она объединяет несколько современных TTS-движков в одном интерфейсе.

Можно выбрать встроенный голос или создать собственный переиспользуемый голос из аудиореференса, написать текст, расставить теги подачи и получить **сразу два варианта с разными seed**, чтобы сравнить их рядом.

Тексты, голосовые референсы, подготовленные данные клонированных голосов и сгенерированное аудио остаются на компьютере. Интернет нужен только для загрузки выбранных моделей и необходимых runtime-компонентов.

### Главное

- 🎙️ **Переиспользуемое клонирование голоса** из WAV, MP3, FLAC, OGG, M4A, AAC и OPUS.
- 🧠 **Шесть независимых TTS-движков** с изолированными Python-окружениями.
- 🎭 **Сегментные теги подачи**: эмоции, шёпот, скорость, дикторская манера, паузы, смех, вздохи и другое.
- 🔤 **Помощь с русскими ударениями** через компактную локальную Gemma 4 и ручную постановку ударения.
- 🎚️ **Stability, скорость и высота голоса**, нормализация и обрезка тишины по краям.
- 🎲 **Два варианта на каждую генерацию** с разными seed и сравнением бок о бок.
- 🖱️ **Drag & Drop** аудиофайлов с визуальной подсветкой зоны сброса.
- 💾 Несохранённые варианты хранятся во **временном кэше**, а не засоряют папку Output.
- 🌗 **Светлая и тёмная темы**.
- 🌍 Языки интерфейса: **английский, русский и украинский**.
- 🔒 **Local-first архитектура** — для обычной генерации не нужен облачный TTS.

## 🎙️ Клонирование голосов

Окно создания голоса учитывает особенности выбранной модели. Сначала выбирается целевой движок, после чего Voxena показывает требования именно к нему.

Если движок умеет сохранять переиспользуемое conditioning-состояние, Voxena готовит его **один раз** при создании голоса и сохраняет локально. Поэтому исходный референс не приходится заново анализировать при каждой новой генерации.

Рекомендации для хорошего референса:

- один чистый голос без других говорящих;
- минимум фоновой музыки, эха и комнатной реверберации;
- короткий, но репрезентативный фрагмент речи;
- **точная транскрипция**, если выбранному движку нужна привязка текста к аудио.

Если модели транскрипция не требуется, соответствующее поле в интерфейсе автоматически скрывается.

Пользовательские голоса хранятся в:

```text
Voices\Custom\<voice-id>
```

Удаление одного голоса удаляет только его референс и подготовленные данные. Остальные голоса и модели не затрагиваются.

## 🎭 Теги подачи

В Voxena теги работают как **состояния на временной линии**, а не как одна глобальная инструкция на весь текст.

### Последовательная смена состояния

```text
[грустно] Я правда думал, что всё получится...
[зло] Но теперь мне это надоело.
```

Первый кусок будет грустным, а второй переключится на злую подачу.

### Теги подряд суммируются

```text
[грустно][шёпотом] Я не хочу, чтобы нас услышали.
```

Между тегами нет текста — значит оба эффекта относятся к одному сегменту.

### Сброс в обычную подачу

```text
[восторженно] У нас реально получилось!
[обычно] Ладно, возвращаемся к отчёту.
```

`[обычно]` очищает активное состояние для следующего фрагмента.

### События на таймлайне

```text
Я действительно думал, что всё получится... [вздох]
Но, видимо, нет. [пауза:1.0]
[зло] Значит, будем исправлять нормально.
```

`[вздох]`, `[смех]` и `[пауза:x]` — это события в конкретной позиции текста, а не постоянные эмоциональные состояния.

### Основные группы тегов

| Категория | Примеры |
|---|---|
| **Эмоции** | `[радостно]` `[восторженно]` `[грустно]` `[зло]` `[спокойно]` `[серьёзно]` `[саркастично]` `[сочувственно]` |
| **Подача** | `[шёпотом]` `[мягко]` `[громко]` `[медленно]` `[быстро]` `[глубже]` `[ярко]` `[диктор]` |
| **События / управление** | `[пауза:0.7]` `[смех]` `[вздох]` `[обычно]` |

Есть английские, русские и украинские алиасы. Например, `[sad]`, `[грустно]` и `[сумно]` означают одно и то же состояние.

> Способ передачи тегов адаптируется под конкретный TTS. Если движок имеет собственные semantic-control теги, Voxena использует их. Для остальных применяется безопасный fallback без глобального искусственного изменения высоты голоса обычными эмоциональными тегами.

## 🔤 Русские ударения и фонетический препроцессинг

Русская речь чувствительна к ударениям, особенно при клонировании голоса. В Voxena есть компактная **локальная Gemma 4**, которая перед синтезом внутренне размечает ударные гласные.

Ударение можно указать и вручную:

1. Выдели одну гласную в редакторе.
2. Нажми кнопку **`´`**.
3. Voxena будет считать эту позицию явным выбором пользователя.

Если в слове ударение поставлено вручную, автоматический обработчик не имеет права добавить в это же слово ещё одно ударение. Сначала разрешаются ручные и автоматические ударения, затем выполняется фонетический проход, и только после него строка передаётся выбранному речевому движку.

Сам видимый текст при этом остаётся удобочитаемым — служебное представление не перезаписывает сценарий в редакторе.

## 🎚️ Как проходит генерация

**Текст** → **Сегментация по тегам** → **Ударения и фонетический проход** → **Локальный TTS** → **Вариант A / Вариант B** → **Постобработка** → **Прослушивание или Save as...**


На каждый запуск Voxena создаёт **два варианта с разными seed**. Их можно сразу сравнить, прослушать, посмотреть waveform, сохранить понравившийся или запустить новую пару.

Поддерживаемые форматы:

- **MP3**
- **WAV PCM**
- **FLAC**
- **OGG**
- **M4A AAC**

Дополнительно доступны 44.1 / 48 kHz, выбор bitrate для lossy-форматов, нормализация громкости и обрезка тишины по краям.

## 🧩 Изолированные runtime-окружения

Современные TTS-проекты часто требуют несовместимые между собой версии Python, PyTorch, Transformers и других библиотек. Voxena не пытается запихнуть их все в одно окружение.

Для каждого движка создаётся отдельный runtime:

```text
Runtime\Engines\<engine-id>
```

Поэтому одна модель может использовать нужную ей версию Transformers, не ломая вторую модель с другим набором зависимостей.

Перед использованием Voxena также выполняет compatibility-check и умеет автоматически исправлять известный drift зависимостей.

## 📁 Где хранятся данные

Все пути расположены относительно `Voxena.exe`.

```text
Voxena.exe
├─ Models\              # скачанные веса моделей
├─ Runtime\             # uv, FFmpeg, Python и окружения движков
├─ Voices\Custom\       # клонированные голоса и conditioning
├─ Cache\Generated\     # временные несохранённые генерации
├─ Output\              # папка, предлагаемая при Save as...
├─ Config\              # настройки
└─ Logs\                # диагностические логи
```

Если ты просто прослушал результат и не сохранил его, Voxena не обязана вечно держать этот файл в `Output` — preview хранится во временном кэше и очищается.

## 🚀 Первый запуск

При первом запуске Voxena показывает выбор моделей. Можно установить сразу несколько движков или нажать **«Не сейчас»** и вернуться к этому позже во вкладке **Models / Модели**.

Для каждой модели отображаются:

- примерный размер на диске;
- рекомендуемый объём VRAM;
- языки;
- лицензия;
- плюсы и ограничения;
- требования к аудиореференсу для клонирования.

Компактный помощник по русским ударениям подготавливается автоматически при необходимости.

## 🛠️ Сборка из исходников

### Требования

- Windows 10 / 11 x64
- Visual Studio 2022 или Build Tools 2022
- workload для .NET desktop build tools
- интернет для NuGet restore и первичной загрузки runtime/model-пакетов

### Release одной командой

```bat
BuildRelease.bat
```

Результат сборки:

```text
Voxena\bin\Release
```

Чтобы создать чистый ZIP для релиза:

```bat
PackageRelease.bat
```

Для разработки также доступны:

```bat
BuildDebug.bat
```

и:

```bat
BuildAndRun.bat
```

Конечному пользователю не требуется отдельно ставить Visual Studio, Python или вручную настраивать ML-окружения. Voxena сама подготавливает managed runtime для выбранных в приложении моделей.

## 🔐 Приватность

Voxena построена вокруг локальной обработки:

- введённый текст обрабатывается локально;
- референсы клонированных голосов остаются локально;
- подготовленные speaker-conditioning данные остаются локально;
- сгенерированное аудио остаётся локально;
- runtime моделей хранится рядом с приложением.

Сеть нужна для скачивания выбранных моделей и зависимостей. Для обычной генерации не требуется аккаунт облачного TTS-сервиса.

## ⚠️ Ответственное использование

Клонированный голос может очень убедительно воспроизводить голос конкретного человека. Используй эту функцию только при наличии необходимых разрешений и не применяй синтезированную речь для мошенничества, выдачи себя за другого человека, травли или намеренного введения людей в заблуждение.

Ограничения лицензий отдельных моделей действуют независимо от Voxena.
